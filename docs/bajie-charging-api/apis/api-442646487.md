## OpenAPI Specification

openapi: 3.0.1

      summary: OAuth2登录
      deprecated: false
      description: >
        OAuth2 Login

        The client needs to first hash the password using SHA256 before
        transmitting it.

        Log in with the OpenAccount account, and a token that allows access to
        the open-api service and web-api service will be returned. 

        When accessing the open-api service, the parameter 'Authorization' needs
        to be added to the request header, and the value should be in the format
        of "Bearer + the returned token".

        For example: Bearer 40c28166946f366741c06e47b4f3729e

        When accessing the web-api service, you need to add the parameter
        'token' to the request header, with the value being the returned token
        only.

        OAuth2 登录

        客户端需先对密码进行 SHA256 哈希后再传输

        用OpenAccount账号登录，返回可访问open-api服务和web-api服务的token，

        访问open-api服务时，需要在请求头上面添加参数'Authorization'，值的格式为Bearer +返回的token

        例如：Bearer 40c28166946f366741c06e47b4f3729e

        访问web-api服务时，需要在请求头上面添加参数'token'，值的格式为返回的token即可
